# Arcane Thief

Character creation: the **Thief** archetype becomes an arcane thief (new heroes only).

- Caster type full mage: can learn every human spell at trainers (like a battle mage).
- AE 22 (battle mage 32), MR +2, starting spells Axxeleratus 3, Blitz 3, Duplicatus 2, Fulminictus 2.
- Keeps all thief talents, dagger aptitude and Dodge; no starting shield (metal shields block spellcasting; caster bucklers are wood).
- Advantage "Arcane Thief": `TaMagiekunde:+8;TaAlchimie:+8;Reg_AE_freq:+1;ZaAxxeleratus:+1;ZaDuplicatus:+1;ZaBlitz:+1;ZaAttributoGE:+1;ZaAttributoFF:+1;ZaFulminictus:+1;ZaIgnisphaero:-3;ZaGardianum:-2;ZaBalsam:-3;ZaSkelettarius:-5;ZaDschinenruf:-5;ZaElementarerDiener:-5;ZaOdem:-5;ZaEscliptifactusSchattenkraft:-5;ZaAeroFugumVakuum:-3;`

Install/Uninstall with the bat files (game closed). Independent of the Armory.
